## 📌 Project Description

**UNO Ultimate** is a browser-based card game inspired by the classic UNO card game. It provides an interactive gaming experience with a modern user interface, AI-controlled opponents, customizable players, and animated card gameplay.

Players can compete against computer-controlled opponents or play with friends using the same device through local pass-and-play multiplayer.

The game includes a complete UNO card deck, automatic card distribution, turn management, special card effects, AI-based opponents, scoring, sound effects, and player statistics.

The project is organized into six development phases, with one major GitHub commit planned for each week.

## 🎮 Game Rules

The game follows the main UNO card-matching mechanics.

- Match cards by color, number, or symbol.
- Use Skip cards to skip the next player's turn.
- Use Reverse cards to change the playing direction.
- Use Draw Two cards to make the next player draw two cards.
- Use Wild cards to select a new color.
- Use Wild Draw Four cards to make the next player draw four cards and change the color.
- Call UNO when you have one card remaining.
- A missed UNO call can result in a two-card penalty.
- The first player to get rid of all their cards wins the match.

**Additional Rule:** The game also supports same-value multi-card play as an additional house rule.
